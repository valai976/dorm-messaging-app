# Dorm Messaging App Project Site

This Node/Express app serves plain HTML documentation. It uses no CSS.

## Run the website

1. Install Node.js and npm.
2. Open this folder in a terminal.
3. Run npm ci.
4. Run npm start.
5. Open http://localhost:3000.

Use a different port with the PORT environment variable if needed.

## Contents

Landing page, documentation index, Quickstart, and eight feature guides. Screenshots show actual JavaFX windows. User-provided screenshots replace matching examples; the remaining screenshots use isolated sample data.

## Repository location

Keep this folder at code/Project-site in the dorm-messaging-app repository.

## Submission

The supplied ZIP contains the complete Node app without node_modules. Run npm ci after extracting it.
