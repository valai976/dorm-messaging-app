Log In

You need an account created on this computer.

  1. Open the Accounts window.
  2. Enter your registered username and password. Usernames are case-sensitive.
  3. Click Log in, or press Enter while the password field is focused.
  4. The Community window opens and displays a welcome message. Select a dorm if none is selected.

If login fails, check your username, password, capitalization, and password spaces. Create an account first if you have not registered.
