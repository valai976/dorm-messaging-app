Dorm Messaging App

A local JavaFX desktop application that helps dorm residents share information, ask questions, and reply to conversations.

Create an account, log in, select a dorm, and join its message feed. Accounts and conversations are saved locally between sessions. Communication between separate computers is outside this version's scope.
