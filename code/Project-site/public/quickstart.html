Quickstart Guide

Requirements

  • JDK 17 and Maven installed, with Java available to Maven.
  • Internet access for the initial Maven dependency downloads.
  • A desktop environment to display JavaFX windows.

Launch with Maven

  1. Clone or download the repository. Select the dev branch, which contains the implemented application. The release branch inspected for this guide still contains placeholder code.
  2. Open a terminal in code/Dorm-Messaging-App, the folder containing pom.xml.
  3. Run mvn clean verify and wait for BUILD SUCCESS.
  4. Run mvn javafx:run.
  5. Wait for the Dorm Messaging - Accounts window to open.

Launch with Eclipse

  1. Open Eclipse and choose File > Import > Maven > Existing Maven Projects.
  2. Choose code/Dorm-Messaging-App as the root directory, select its POM, and finish the import. Skip this step if it is already imported.
  3. Right-click the imported project and select Run As > Maven build....
  4. Use clean verify as the Goals value and run it. Wait for a successful build.
  5. Open Maven build again, set Goals to javafx:run, and click Run.
  6. The Accounts window opens. Create an account or log in.

First use

Register, log in, then select a dorm.

Local data

Saved data is stored in .dorm-messaging-app/data.xml under your user home folder. Keep that file to retain accounts and conversations. If saving fails, use Retry save in Accounts or Save in Community before closing.

JavaFX 21 is declared in the POM. The bundled README contains outdated grocery-list and coverage details; the POM sets the included-package coverage minimum to 95%.
