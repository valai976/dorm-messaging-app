Select a Dorm

  1. Log in to open the Community window.
  2. Open the Select your dorm dropdown at the top.
  3. Choose NORTH_HALL, SOUTH_HALL, or EAST_HALL.
  4. The feed updates to show posts for the selected dorm. The selection is saved automatically if saving succeeds.

You must log in before selecting a dorm. You can switch dorms using the same dropdown.
