View Dorm Messages

  1. Log in and select a dorm.
  2. Read the messages in the Dorm posts list. Each entry shows the author, posting time, and message text.
  3. Scroll the list if there are more posts than fit in the window.
  4. Select a post to see its replies below.

If the feed is empty, confirm that a dorm is selected. That dorm may not have any posts yet.
